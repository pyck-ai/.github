# pyck-ai/.github

This repository ships two things for the [pyck-ai](https://github.com/pyck-ai)
GitHub organization:

1. **Org-wide community-health defaults**: issue forms, a PR template, a
   security policy, and a code of conduct that GitHub auto-applies to every
   repo in the org that doesn't ship its own copy. See
   [docs/community-health.md](./docs/community-health.md).
2. **Opt-in agent protocols**: standards that AI coding assistants like
   [Claude Code](https://www.anthropic.com/claude-code) and
   [opencode](https://opencode.ai) load to keep issues, pull requests, and
   commits consistent across humans and agents. The entry point is
   [AGENTS.md](./AGENTS.md); adoption instructions are in
   [docs/agent-protocols.md](./docs/agent-protocols.md).

A third, smaller part: [`badges/`](./badges/README.md) holds static SVG
outline badges (severity, status, kind, confidence) in light and dark, for
links from comments. Generated by `scripts/generate-badges/`; regenerate with
`task generate:badges`.

How to consume updates, how contributing works here, and how the generated
`.github/` files relate to their sources in `src/`:
[docs/contributing.md](./docs/contributing.md). Changes to the files under
`.github/` propagate to every repository in the `pyck-ai` org, so review them
carefully.
