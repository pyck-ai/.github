Org-wide GitHub defaults for the [pyck-ai](https://github.com/pyck-ai)
organization.

## What is pyck-ai/.github?

GitHub applies the files under `.github/` to every pyck-ai repository that does
not ship its own copy; consumers need no setup. A repository overrides a
default by adding the same file itself.

Out of the box, pyck-ai/.github includes:

- **Issue forms**: `.github/ISSUE_TEMPLATE/{1-defect,2-feature,3-task}.yml`,
  edited in place, and the issue chooser's links in
  `.github/ISSUE_TEMPLATE/config.yml`.
- **PR template**: `.github/PULL_REQUEST_TEMPLATE.md`, edited in place.
- **Community files**: [`.github/CODE_OF_CONDUCT.md`](./.github/CODE_OF_CONDUCT.md),
  [`.github/CONTRIBUTING.md`](./.github/CONTRIBUTING.md),
  [`.github/SUPPORT.md`](./.github/SUPPORT.md) and
  [`.github/ACCESSIBILITY.md`](./.github/ACCESSIBILITY.md).
- **Security**: [`.github/SECURITY.md`](./.github/SECURITY.md) and the form for
  private vulnerability reports, `.github/VULNERABILITY_REPORT.yml`.
- **Org profile**: [`profile/README.md`](./profile/README.md), shown on the
  organization page.
- **Badges**: static SVG badges that comments link by raw URL, generated by
  [`scripts/generate-badges/`](./scripts/generate-badges/main.go).

Changes here affect every repository in the org, so review them as org-wide
changes.

## Getting started

The issue forms and the PR template are plain files: edit them in place. Only
the badges are generated; edit the generator, never an SVG, then re-sync:

```sh
task generate  # regenerate the badges
task ci        # check that everything is in order (CI runs this)
```

Prerequisites: [Go](https://go.dev) 1.23 and [Task](https://taskfile.dev). Run
`task --list` for every other command.
